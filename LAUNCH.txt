通用信息收集爬虫 - 运行说明
================================

方式一：直接运行可执行文件（推荐）
------------------------------------
1. 进入 dist 文件夹
2. 双击运行 InfoScraper.exe
3. 即可打开爬虫工具界面

注意：
- 首次运行可能会稍慢（约 5~15 秒），因为需要解压资源。
- 如果被杀毒软件拦截，请选择「允许运行」或添加到信任列表。
- 可视化选择器和 JS 渲染功能需要额外安装 Chromium 浏览器：
  在当前电脑安装 Python 和 Playwright 后执行：
      playwright install chromium
  否则这两个功能会提示未安装浏览器。

方式二：源码运行
------------------------------------
1. 安装依赖：
      pip install -r requirements.txt
2. （可选）安装浏览器：
      playwright install chromium
3. 启动程序：
      python main.py

文件说明
------------------------------------
- dist/InfoScraper.exe    打包好的单文件可执行程序（约 95MB）
- main.py                 源码入口
- gui.py                  界面代码
- README.md               完整功能说明
